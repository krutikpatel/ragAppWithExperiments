# EXP-0040 — Span-level versus chunk-level citation

- **Status:** VALID
- **Date:** 2026-09-25
- **Run IDs:** `run_20260925_210039_c048` (dev) · `run_20260925_210747_6539` (unanswerable)
- **Git SHA:** 3034466 (`git_dirty=0`) · **Prompt:** `span_answer@v1`
- **Compared against:** EXP-0006 / EXP-0007 · **Cost:** $0.02995 + $0.01280 = **$0.0428**
- **Parser:** `citation-v3` · **Detector:** `refusal-lexical-v3`
- **Hypothesis:** H-028

## Question
Is a citation that quotes its source better than one that only names it? Span-level
citation is only worth its cost if the quoted span can be trusted — so the question is
both "does quality change" and "are the quotes real".

## Configuration diff
```yaml
- generator_prompt: baseline_answer@v1
+ generator_prompt: span_answer@v1     # [doc:<id>|<exact quote, <=12 words>]
```

## Two bugs that had to be fixed before this run could mean anything
**`citation-v2` matched span-form citations as nothing.** `[doc:abc12345|Click Save]`
returned no document id at all, so every citation metric would have read **zero** and
this experiment would have "measured" that span citations destroy citation quality.
`citation-v3` parses both forms and a test asserts it parses every v2 form identically.

**`refusal-lexical-v2` scored a numbered refusal as an answer** (MIS-038). This run's
false-answer rate read **1.0000** before the fix. It is 0.8889 after — still bad, but a
measurement rather than an artifact.

## Observations

**One quoted span in five is not in the document it is attributed to.** `span_support`
is **0.7964** on dev — of 4.87 spans per answer, roughly one is a quote the cited
article does not contain. The match is whitespace- and case-insensitive but otherwise
exact, deliberately: a model that paraphrases while claiming to quote has not supported
its claim. On `unanswerable` it is worse at 0.7429, which is the direction that makes
sense — there is less real text to quote, so more gets invented.

**This is the core finding, and it inverts the technique's selling point.** Span-level
citation *looks* more rigorous than naming a document: it shows its work. But a document
id is either in the gold set or not, and that is checkable; a quoted span is checkable
too, and **20% of them fail the check**. Span citation delivers a verifiable artifact and
then fails the verification one time in five. A reader who trusts the quotes is worse off
than one who only had document ids, because the quotes carry an air of proof that 79.6%
support does not earn.

**Document-level citation precision got worse too** — 0.5455 → 0.4353, the largest
citation-precision drop in the phase. Asking for a quote did not make the model pick
better documents; it made it pick more of them, less carefully.

**Step coverage fell to 0.0193, the lowest recorded anywhere in this project.** Same
mechanism as EXP-0039 and more extreme: an answer built out of quotable fragments is an
answer about the articles, not a procedure the user can follow. The two citation
experiments agree on this precisely, from different prompts.

**And it never refuses.** Zero refusals in 100 dev questions and 5 in 45 unanswerable
ones, which is the EXP-0039 pattern repeated: a hard citation requirement makes
"describe a cited document" the path of least resistance, and describing is always
possible.

## Anomalies
`spans_cited` averages 4.87 against `top_k = 5` documents — the model quotes almost
exactly once per available document, suggesting it is working through the context
mechanically rather than selecting evidence for claims.

## Hypothesis
H-028 predicted `span_support` **below 0.80** and document-level citation precision
**within its MDD of 0.080**. **First half right — 0.7964, just inside the line.** Second
half **wrong**: precision fell 0.1102, well outside the MDD. I reasoned that "naming the
right article is an easier task than quoting it" and therefore that document-level
precision would hold; instead the demand for quotes degraded document selection too. I
had the right worry about faithfulness and underestimated how much the citation format
reshapes the whole answer.

## Decision
**Control retained; not promoted.** Worse on every reported metric except citation
recall, and its distinguishing artifact fails verification 20% of the time.
