## Question
Does making a citation a precondition for writing a step — and naming refusal as the
explicit fallback — reduce false answers on questions the corpus cannot answer?

## Configuration diff
```yaml
- generator_prompt: baseline_answer@v1
+ generator_prompt: enforced_answer@v1
```
One dimension. Same task, format, language and URL rule as the control; only the strength
of the citation requirement changes, plus the instruction to drop an uncitable step
rather than write it uncited.

## Results
| Metric | Control | This run | Δ |
|---|---|---|---|
| **False-answer rate (`unanswerable`, n=45)** | **0.2667** | **0.8444** | **+0.5778** |
| False-refusal rate (`dev`, n=66 with gold in context) | 0.0299 | **0.0000** | −0.0299 |
| Refusals on `unanswerable` | 33 / 45 | **7 / 45** | −26 |
| Refusals on `dev` | 8 / 100 | **0 / 100** | −8 |
| Citation precision | 0.5455 | 0.4892 | −0.0564 |
| Citation recall | 0.6100 | 0.6567 | +0.0467 |
| **Step coverage** (n=32) | **0.1934** | **0.0329** | **−0.1605** |
| Cited nothing | 0.0700 | 0.0000 | −0.0700 |
| Answers containing a URL | 0.0000 | 0.0000 | 0.0000 |

**The system stopped refusing anything at all** — zero refusals across 145 questions on
both splits — and its false-answer rate more than tripled.

## Observations

**Enforcing citations removed refusal as an option.** The prompt says every step must
carry a citation and that refusal is the fallback if nothing supports an answer. The
model resolved that tension the other way: instead of refusing, it writes a numbered,
cited statement **about** the articles. *"1. The provided articles cover currency changes
for Wix products, not Squarespace. Please note: you would need Squarespace-specific
guidance…"* — cited, formatted, and not an answer to the question. Under any metric that
counts refusals it is an answer, and to a user it reads as one.

**Step coverage collapsed to 0.0329, and that is the same phenomenon measured from the
other side.** The control's answers contain 19.3% of the reference procedure's steps;
these contain 3.3%. The answers stopped being procedures and became descriptions of
documents. A citation requirement applied to every step makes describing a source easier
than following it.

**Citation recall rose while precision fell.** +0.0467 recall, −0.0564 precision: the
model cites *more* documents, including more wrong ones. `cited_nothing` went to exactly
zero — it always cites something now, which is precisely what the prompt demanded and
precisely why the citation became uninformative.

**False refusals went to zero, which is not a win.** 0.0299 → 0.0000 looks like the good
half of a trade-off. It is the same fact as the rest: a system that never refuses has no
false refusals. Read next to a false-answer rate of 0.8444 it is a description of a
system that always answers.

## Anomalies
The 7 refusals that did survive on `unanswerable` are the questions where no article was
even topically adjacent — the model had nothing to describe. That is consistent with the
mechanism above: refusal now requires the *absence* of citable text, not the absence of
an answer.

## Hypothesis
H-027 predicted the false-answer rate would **fall** by more than 0.05 and the
false-refusal rate would **rise** — a trade. **Both halves are wrong, and in the same
direction:** false answers rose by 0.5778 and false refusals fell to zero. I reasoned
that naming refusal as the explicit fallback "should push behaviour toward refusing".
It pushed the opposite way, because the other instruction in the same prompt — cite
every step — is easier to satisfy by describing a document than by declining. I also
wrote that I expected the two numbers to move by dissimilar amounts and that "the
interesting question is which"; they moved in dissimilar amounts and in the wrong
directions, which was not on the list.

## Decision
**Control retained; not promoted.** The largest single regression on the axis's hard
target in the phase.
