## Observations
- With 10 candidates, Jev picks 5 of the dense top 10. 188 of 200 questions got a
  different top-5 set from the dense control (run 1), so it does reorder heavily inside
  that window.
- `source:expertwritten` (n=100) again moved up against the control: +0.120 / +0.110
  (p = 0.005 / 0.013), `source:simulated` −0.040 / −0.050 (p = 0.48 / 0.35). Same
  direction as EXP-0065 in all four Jev runs; still a post-hoc slice (OQ-056).
- Five times cheaper and about five times faster at p95 than EXP-0065.
